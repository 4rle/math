# ホーム画面へのインストール

Focusgold HelperはPWAとしてインストールできます。Cloudflareへ通常どおりデプロイすれば利用でき、ストアへの登録や追加の有料サービスは不要です。

## PixelなどAndroidのChrome

1. デプロイ済みのHTTPSのURLを通常のChromeタブで開きます。
2. 左上メニュー → General →「アプリをインストール」を押し、Chromeの確認画面でインストールします。
3. ホーム画面の白いFのアイコンから開きます。ブラウザーのアドレスバーがない独立した画面で利用できます。

Chromeの︙メニュー →「ホーム画面に追加」→「インストール」からも追加できます。ブラウザーによっては「アプリをインストール」という項目名です。Generalのボタンで確認画面が開かない場合は、その場に表示される手動追加の案内に従ってください。シークレットモードではインストールできません。

## iPhone

Safariで公開URLを開き、共有ボタン →「ホーム画面に追加」を選びます。自動のインストール確認画面には対応していないため、Safariの共有操作を使用します。

## オフラインと更新

最初はオンラインで開き、画面の読み込みを完了させてください。アプリの表示に必要なファイルが端末へ保存され、次回からはオフラインで起動・評価・端末内保存ができます。アカウントへの新規ログイン・再認証・端末間同期には通信が必要です。端末内に保存した同期待ちの記録は、通信が戻ると既存の同期処理で送信されます。

更新が見つかった場合はGeneralに案内を表示します。操作中の強制再読み込みは行いません。このサイトのブラウザータブとインストールしたアプリをすべて閉じ、開き直すと更新されます。学習記録はIndexedDBにあり、表示用キャッシュの更新では削除しません。

## 実装と開発時の確認

`npm run build`はViteのビルド後、`scripts/build-sw.mjs`で`dist/sw.js`を生成します。ビルドしたHTML・JS・CSS・フォント・マニフェスト・アイコンだけを明示的にキャッシュします。API、認証ヘッダー付き通信、URLクエリー付きリソース、個人向け応答は追加保存しません。オンラインの画面遷移はネットワークを優先し、オフラインでは同梱のHTMLを返します。古い表示用キャッシュは更新版の有効化時に削除します。

開発用の`npm run dev`ではService Workerを登録しません。本番と同じ動作は次のコマンドで確認します。

```sh
npm run build
npm run preview
```

`localhost`・`127.0.0.1`はローカルでのService Worker確認に使用できます。スマートフォンから通常のLANのHTTPアドレスを開いた場合はインストール条件を満たさないため、CloudflareのHTTPSのURLを使ってください。Cloudflareのビルドコマンドはこれまでどおり`npm run build`です。

`npm run build`後の`npm run test:e2e -- tests/pwa.spec.ts`では、本番ファイルを配信して以下を検証します。

- Chromiumのインストール条件、マニフェストとアイコン寸法、インストールボタンの連携。
- オフライン再読み込みと評価の保存、API応答をキャッシュしないこと。
- 更新待機中の入力保持、古い画面を閉じた後の更新、保存済み設定の維持。

PixelやiPhoneの実機でのインストール操作は、この自動テストには含みません。
