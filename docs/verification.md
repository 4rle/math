## ログイン・同期、タイトル、スクロール演出

- Supabase Auth の新規登録、ログイン、メール確認案内、再設定メール、ログアウトを実装。設定未完了なら端末内保存を継続。
- ゲストとアカウント別に IndexedDB を分離。通信失敗・競合時はローカルの記録を保持。ゲスト取り込みは明示操作で行う。
- 同期はバージョン比較で更新し、競合時は端末のバックアップ保存と確認後に内容を選ぶ。接続が戻ったとき・画面に戻ったとき・約15秒ごとに再試行。
- カードへタイトルを全文折り返しで表示。スクロール演出は一覧ごとに1つの IntersectionObserver を使い、一度だけ上昇・フェード。ドラッグの transform と独立し、フォーカス時は即表示、動き停止に対応。
- `npm run check`：型チェック・ビルド、31件の単体／SQLテスト、30件のブラウザーテストが成功。
- PostgreSQL（PGlite）で SQL 原本を実行し、未認証の拒否、RLS による他人の記録の不可視化、直接更新の拒否、初回作成、古いバージョンの更新拒否、再適用を確認。
- ブラウザーでは認証 API のテスト用応答を使用。独立した2端末相当の同期、別ユーザーの分離、ゲスト取り込み、ログアウト、通信切断・再読み込み・競合、同期応答待ち中の追加入力、メール案内、タイトル・スクロールを確認。
- 接続情報あり／なしの本番ビルドをそれぞれ実行し、CSP の connect-src が指定先だけ追加されることを確認。秘密キー・不正URLのビルド拒否もテスト。
- 本番 Supabase プロジェクトは未作成のため、実サービスへの接続、確認・再設定メールの到達は未検証。`docs/account-setup.md` の設定後に本番確認が必要。
