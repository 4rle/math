# Focus Gold — 学習記録

Focus Gold Ⅰ＋A・Ⅱ＋B・Ⅲ＋C の登録問題を、番号カードから記録する Web アプリ。React / TypeScript / Vite 製で、Cloudflare Workers の Static Assets または Cloudflare Pages にデプロイできます。

主画面の常設要素は左上のメニュー、参考書タブ、カードフィールドだけです。大きなヘッダー、タイトル、Hero、統計パネルはありません。問題は未登録から始まります。参考書の内容や問題番号を自動生成しません。

## 開発

Node.js 22.12 以上（検証環境：24.19.0）と npm を使用します。

```sh
npm ci
npm run dev
```

左上メニュー →「問題の登録と管理」から参考書と ☆ を選び、問題番号を入力してください。CSV の確認付き取り込みにも対応しています。

```csv
book,stars,number,unit
1A,3,125,三角比
1A,4,128,三角比
2B,3,42,
3C,4,61,
```

CSV の重複取り込みで学習履歴は消えません。難度を変更する場合は取り込み確認でチェックが必要です。`unit` 列がなければ既存の単元を維持し、列があれば空欄も含めて更新します。不正行がある場合は取り込まず、行番号と理由を表示します。

## 学習と保存

- 問題カードを選び、A〜E を押すだけで記録。保存に失敗すると選択画面を残して再試行できます。
- カードは指で横にドラッグ、または少し長押しして上下左右へ動かせます。離すと元の位置に戻ります。マウス・ペンでも操作可能です。
- 縦スワイプはスクロール、短いタップは記録。ドラッグで並び順や学習状態は変わりません。メニューの「表示と動き」や OS の「動きを減らす」で演出を停止できます。
- 未着手を優先し、今日の新規候補に小さな星を表示。他のカードも選べます。
- B は14日後、C・D は7日後から復習候補。E はすぐに要再学習の候補。いずれもメニューから調整できます。
- A は通常候補から外れ、登録した模試の確認期間に範囲内のものだけ再提示。確認期間中に A を記録すると、同じ模試で再提示しません。
- 日付判定はすべて日本時間。復習候補日は実際の学習日を基準に計算します。
- 履歴・メモ・進捗・表示範囲・動きの設定はメニューに集約。
- IndexedDB に端末内保存。ログイン、サーバー送信、端末間の自動同期はありません。
- 完全バックアップは JSON、問題登録一覧は CSV で出力。JSON 復元は内容を確認したうえで既存データを置き換えます。

**ブラウザーのデータ削除や端末紛失に備え、定期的に JSON バックアップを保存してください。** 保存先はオリジン単位なので、本番ドメインとプレビューのデータは別です。ドメインを移す場合も JSON を使って移行します。複数タブの同時書き込みでは古いデータによる上書きを拒否します。エラーが出たタブを再読み込みしてください。

## 検証

```sh
npm run build       # 型チェック + 本番ビルド
npm test            # 候補計算、日付、CSV、バックアップのテスト
npm run test:e2e    # Chromium で主要操作と5つの画面サイズを検証
```

E2E は環境内の `/usr/bin/chromium` を使用します。他の場所にある場合は `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` で指定できます。システムの Chromium がなければ Playwright 標準のブラウザーを使用します。未導入の場合は `npx playwright install chromium` で導入してください。

## Cloudflare にデプロイ

### Workers Static Assets（推奨）

```sh
npx wrangler login
npm run deploy
```

`wrangler.jsonc` に Static Assets と SPA フォールバックを設定済みです。初回デプロイ時に Cloudflare のアカウントを選択します。Worker 名は `focusgold-orbit`。必要なら `wrangler.jsonc` の `name` を変更してください。データベースや API キー、サーバー側の環境変数は不要です。Cloudflare の認証情報はリポジトリに保存しないでください。

Cloudflare の Git 連携を使用する場合：ビルドコマンド `npm run build`、デプロイコマンド `npx wrangler deploy`、ルートはこのリポジトリです。

### Cloudflare Pages

Git 連携でビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定してください。`404.html` を生成しないため Pages の SPA フォールバックが使われます。

### ローカルの Cloudflare ランタイム

```sh
npm run cf:dev
```

`public/_headers` で CSP 等のレスポンスヘッダーを指定しています。外部 CDN・フォント・解析サービス・写真解析 API は使用していません。

## 構成

- `src/model.ts`：登録、履歴からの派生値計算、候補判定、模試、CSV・バックアップ検証
- `src/storage.ts`：IndexedDB の読み書き、トランザクション完了確認、競合検出
- `src/FloatingCard.tsx`：指・マウスのドラッグ、ばねでの復帰、タップ・スクロールの判別
- `src/App.tsx`：カードフィールド、参考書切り替え、評価画面、メニュー
- `src/panels.tsx`：問題管理、設定、模試、履歴、進捗、データ管理
- `src/style.css`：ダークテーマ、セーフエリア、縦横画面、動きを減らす設定
- `docs/focusgold_spec.md`：提供された仕様書

写真の自動解析、Google カレンダー連携、自動同期、PWA は仕様書どおり将来拡張の範囲です。
