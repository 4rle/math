# Focus Gold — 学習記録

Focus Gold Ⅰ＋A・Ⅱ＋B＋C・Ⅲ＋C の登録問題を、番号カードから記録する Web アプリ。React / TypeScript / Vite 製で、Cloudflare Workers の Static Assets または Cloudflare Pages にデプロイできます。

主画面の常設要素は左上のメニュー、参考書タブ、カードフィールドだけです。大きなヘッダー、タイトル、Hero、統計パネルはありません。提供された2冊分の CSV から、Ⅰ＋A の303問・Ⅱ＋B＋C の411問、計714問を初期登録します。Ⅲ＋C は未登録のままです。番号・難度・タイトル・ページは提供データを使用し、問題文や解答は掲載しません。

## ログインと端末間同期

左上メニュー → General → Account & sync（アカウントと同期）から、新規登録・ログイン・パスワード再設定ができます。認証・同期には Supabase の設定が必要です。未設定時は従来の端末内保存で使えます。

**ブラウザーだけで行う初期設定は [ログイン・同期の設定手順](docs/account-setup.md) を参照してください。** SQL の適用、公開 URL、Cloudflare の2つのビルド環境変数、再デプロイまで説明しています。

開発時は `.env.example` を参考に、`.env.local` に公開用の接続情報を設定します。`service_role` や `sb_secret_` キーは使用しません。

## アプリとしてインストール

CloudflareへデプロイしたHTTPSのURLを開き、左上メニュー → General →「アプリをインストール」からホーム画面へ追加できます。PixelなどAndroidのChromeでは、Chromeの︙メニュー →「ホーム画面に追加」→「インストール」からも追加できます。iPhoneではSafariの共有 →「ホーム画面に追加」を使います。

初回はオンラインで開いてください。その後はオフラインでも起動して、問題の評価・端末内への保存ができます。ログインや端末間同期には通信が必要です。更新版は操作中に強制再読み込みせず、このサイトのタブとアプリをすべて閉じて開き直すと適用されます。[インストール・更新・開発時の確認](docs/pwa.md)を参照してください。

## 開発

Node.js 22.12 以上（検証環境：24.19.0）と npm を使用します。

```sh
npm ci
npm run dev
```

初回はそのままカードを選んで使えます。☆1〜4をすべて表示する初期設定で、「表示する問題」から☆3・4だけに絞れます。手動追加は左上メニュー →「問題の登録と管理」から行えます。CSV の確認付き取り込みにも対応しています。

Ⅱ＋B＋C の内部キーは互換性のため `2B` を維持しています（CSV 入力では `2BC` も受け付けます）。番号は正の整数のほか、`B1.1`・`B2.1`・`C1.79` のような接頭辞付き形式に対応します。難度・表示範囲・模試は☆1〜4を扱えます。タイトルはカードにも表示します。長いタイトルは省略せず折り返し、ページは開いた「問題情報・メモ・学習履歴」内に表示します。

既存端末には未登録の例題だけを一度追加します。同じ参考書・番号の ID、学習履歴、難度、メモ、単元、設定は上書きしません。追加後に削除した例題は再読み込みで復活しません。バックアップの明示的な復元はその内容を優先し、同梱データを再追加しません。

```csv
book,stars,number,unit
1A,3,125,三角比
1A,4,128,三角比
2B,3,42,
3C,4,61,
```

CSV の重複取り込みで学習履歴は消えません。難度を変更する場合は取り込み確認でチェックが必要です。`unit` 列がなければ既存の単元を維持し、列があれば空欄も含めて更新します。不正行がある場合は取り込まず、行番号と理由を表示します。

## 学習と保存

- 問題カードを開き、左E→D→C→B→右Aのスライダーで記録。段階までドラッグして離すと保存します。タップは選択だけで、記録ボタンからも確定できます。初期位置は未選択扱いで、段階の間・キャンセル・フォーカス喪失では保存しません。保存失敗後は選択を残して再試行できます。
- 横スワイプで、メニュー面とタイル面が直角につながった一つの立体が回転します。開くと左80％がメニューになり、カード画面は89.5度回転して、両端が左から約80％の位置に集まるほぼ真横の状態になります。回転体とは別に、スワイプ確定から0.75秒待って黒地・金文字の「Focusgold」の背表紙が降下し、合計2.5秒で右半分を満たします。閉じる回転中は隠れ、開閉の変形や慣性は変更しません。タブバーはカードより手前の独立した層にあり、正面を保ったまま右へスライドしてフェードアウトします。ハンバーガーは影・縁・塗りのない黒い3本線だけで、左上から右上へ移動します。ボタン・キーボードでも操作できます。
- カードは角丸のない四角いガラス面です。長押しして上下左右へ動かせます。離すと元の位置に戻ります。マウス・ペンはそのままドラッグできます。
- 縦スワイプはスクロール、短いタップは記録。ドラッグで並び順や学習状態は変わりません。General → Motion（表示と動き）や OS の「動きを減らす」で演出を停止できます。
- 未着手を優先し、今日の新規候補に小さな黒い菱形を表示。他のカードも選べます。
- B は14日後、C・D は7日後から復習候補。E はすぐに要再学習の候補。いずれもメニューから調整できます。
- A は通常候補から外れ、登録した模試の確認期間に範囲内のものだけ再提示。確認期間中に A を記録すると、同じ模試で再提示しません。
- 日付判定はすべて日本時間。復習候補日は実際の学習日を基準に計算します。
- メニューはLibrary・Display・Study・Exams・Progress・General。Account・History・Data・MotionはGeneral内に集約。詳細設定はメニューの白い面が右端へ広がる全画面で開き、戻るとGeneralまたはメニューへ復帰します。
- IndexedDB に端末内保存。ログイン中は Supabase に同期し、同じアカウントの端末間で共有します。ゲストと各アカウントのキャッシュは分離します。
- スクロールで下のカードが静かに浮かび上がります。ドラッグと別の変形で動かすため、遊びの操作を妨げません。OS・アプリの動き停止設定に従います。
- 完全バックアップは JSON、問題登録一覧は CSV で出力。JSON 復元は内容を確認したうえで既存データを置き換えます。

**ブラウザーのデータ削除や端末紛失に備え、定期的に JSON バックアップを保存してください。** 保存先はオリジン単位なので、本番ドメインとプレビューのデータは別です。ドメインを移す場合も JSON を使って移行します。複数タブの同時書き込みでは古いデータによる上書きを拒否します。エラーが出たタブを再読み込みしてください。

## 検証

```sh
npm run build       # 型チェック + 本番ビルド + PWAのキャッシュ生成
npm test            # 候補計算、日付、CSV、バックアップのテスト
npm run test:e2e    # 上のbuild後に実行。主要操作・画面サイズ・本番PWAを検証
```

E2E は環境内の `/usr/bin/chromium` を使用します。他の場所にある場合は `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` で指定できます。システムの Chromium がなければ Playwright 標準のブラウザーを使用します。未導入の場合は `npx playwright install chromium` で導入してください。

## Cloudflare にデプロイ

### Workers Static Assets（推奨）

```sh
npx wrangler login
npm run deploy
```

`wrangler.jsonc` に Static Assets と SPA フォールバックを設定済みです。初回デプロイ時に Cloudflare のアカウントを選択します。Worker 名は `focusgold-orbit`。必要なら `wrangler.jsonc` の `name` を変更してください。端末内保存だけなら追加設定は不要です。ログイン・同期を使う場合は、Supabase の設定と2つのビルド環境変数が必要です。Cloudflare の認証情報はリポジトリに保存しないでください。

Cloudflare の Git 連携を使用する場合：ビルドコマンド `npm run build`、デプロイコマンド `npx wrangler deploy`、ルートはこのリポジトリです。

### Cloudflare Pages

Git 連携でビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定してください。`404.html` を生成しないため Pages の SPA フォールバックが使われます。

### ローカルの Cloudflare ランタイム

```sh
npm run cf:dev
```

`public/_headers` で CSP 等のレスポンスヘッダーを指定しています。外部 CDN・フォント・解析サービス・写真解析 API は使用していません。

## 初期データの元ファイル

`data/focusgold-1a.csv` と `data/focusgold-2bc.csv` は提供された CSV の原本です。内容の変更なしで保存しています。ブラウザー用データは `python3 scripts/build-catalog.py` で生成し、`python3 scripts/build-catalog.py --check` で原本との一致を確認できます。Python はデータ更新時だけ必要で、通常の開発・Cloudflare ビルドには不要です。

画面は白背景と黒文字、サンセリフ体、英語の見出しを基調にしています。問題タイトルや操作の説明は日本語を維持します。参考書タブは白黒のフラットなバーで、選択中だけ黒地に白文字になります。カード・評価画面・スライダーには指定の[LiquidGlass](https://github.com/ybouane/liquidglass)を採用し、共有のWebGL描画器で屈折・縁の反射・影を描きます。メニューは白いフラットな側面で、タイル面と辺を共有して回転します。WebGLが利用できない場合もCSSのガラス表現で操作できます。[組み込み方と依存関係](docs/liquid-glass.md)を参照してください。既存ユーザーの記録とデプロイ先を維持するため、内部の IndexedDB 名と Worker 名 `focusgold-orbit` は変更していません。

## 同期の実装

- `src/AccountPanel.tsx`・`src/useStudyData.ts`：メール認証、アカウント切り替え、同期状態、ゲスト記録の取り込み
- `src/sync.ts`：アカウント別の IndexedDB キャッシュ、オフライン待機、バージョン比較と競合の確認
- `src/cloud.ts`：Supabase SDK による認証、ユーザーに紐づけたトークンでのデータ通信
- `supabase/migrations/001_study_sync.sql`：RLS、本人限定の取得、比較更新による保存
- `src/CardReveal.tsx`：一覧ごとに1つの IntersectionObserver を使用するスクロール演出

アカウントの同期はスナップショット単位です。自動で競合を混ぜず、端末のバックアップを保存してから採用する内容を選びます。SQL テストは PGlite の PostgreSQL で認証・RLS・競合を実行し、ブラウザーテストは認証 API のテスト用応答で2つの独立したブラウザーを使います。本番 Supabase への接続・メール送信を行うテストではありません。

## 評価スライダーの触覚フィードバック

対応ブラウザーでは、ユーザーが各段階へ移動したときにVibration APIで短い振動を要求します。iPhoneのSafariなどAPI非対応の環境ではWebアプリから振動を発生させられません。文字・目盛り・吸着するつまみは同じ操作で使えます。キーボードは矢印・Home/Endで選択、Enter/Spaceで確定。初期位置のまま開いただけではEを記録しません。

Pixel / Android Chromeで振動がない場合は、端末のサイレントモードを解除し、General → Motion →「振動をテスト」をタップしてください。テストは60msの振動を2回要求し、受付・拒否・非対応を表示します。APIが受け付けても実際の振動を保証するものではありません。Chromeの公開Android実装には、サイレントモードで振動しない条件があります。

段階ごとの振動は25ms、次の開始まで55ms以上の間隔を置きます。短時間に通過した点は上限付きのキューで順番に送り、後続の要求が前の振動を途中で置き換えないようにします。キャンセルや画面非表示・フォーカス喪失では保留分を破棄します。
